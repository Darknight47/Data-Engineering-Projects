## Project 02 🚉🌧️🚗
### Road Weather & Traffic Intelligence

Road Weather & Traffic Intelligence is a Data Engineering project that combines data from the Swedish Transport Administration (Trafikverket) and Weather Open API to explore how weather conditions affect road traffic.

The goal is to build a reliable, analytics-ready data platform using **Azure Databricks and Databricks Asset Bundles (DAB)**.

The platform will ingest road weather observations, traffic flow measurements, and relevant weather data, transform and validate the data through a Bronze, Silver, and Gold architecture, and provide curated datasets for reporting and analysis.

### Project Objectives

- Build a reusable and maintainable data ingestion pipeline.
- Work with multiple APIs and different data structures.
- Handle incremental ingestion, schema changes, data quality, and pipeline reliability.
- Apply the Medallion Architecture (Bronze, Silver, Gold) with a clear purpose for each layer.
- Use Databricks Asset Bundles for deployment and environment management.
- Prepare for the Databricks Data Engineer Associate certification.

### Expected Outcome

An analytics-ready data platform that enables users to explore traffic patterns under different weather conditions and identify potential relationships between weather and traffic disruptions.
