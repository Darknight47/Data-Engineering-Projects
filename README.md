### Open API Data Platform

A learning-focused data engineering project built with Python, PySpark, and Databricks.

## Objectives

- Build a reusable framework for ingesting data from public APIs.
- Implement Bronze, Silver, and Gold data layers.
- Learn data quality, schema management, retries, and idempotent processing.
- Manage Databricks resources using Declarative Automation Bundles.
- Practice Git workflows, automated testing, CI/CD, and production-oriented engineering.
