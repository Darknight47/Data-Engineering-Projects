## Project 01 🎮🗄️🗃️
### Open API Data Platform

A learning-focused data engineering project built with Python, PySpark, and Databricks.

### Project Objectives

- Build a reusable framework for ingesting data from public APIs.
- Implement Bronze, Silver, and Gold data layers.
- Learn data quality, schema management, retries, and idempotent processing.
- Manage Databricks resources using Declarative Automation Bundles.
- Practice Git workflows, automated testing, CI/CD, and production-oriented engineering.

## Project 02 🚉🌧️🚗
### Road Weather & Traffic Intelligence
### Objective

> Explore the relationship between weather conditions and traffic volume on selected Swedish roads.  
(The goal is to build a reliable, analytics-ready data platform using **Azure Databricks and Databricks Asset Bundles (DAB)**.)

**Example questions:**  
- Does traffic volume change during heavy rain or snowfall?
- How does temperature relate to road weather conditions?
- Are certain weather conditions associated with unusual traffic patterns?

### Project Objectives

- Build a reusable and maintainable data ingestion pipeline.
- Work with multiple APIs and different data structures.
- Handle incremental ingestion, schema changes, data quality, and pipeline reliability.
- Apply the Medallion Architecture (Bronze, Silver, Gold) with a clear purpose for each layer.
- Use Databricks Asset Bundles for deployment and environment management.
